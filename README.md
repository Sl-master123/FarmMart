# 🌾 FarmMart – Agricultural Management Platform

FarmMart is a comprehensive mobile application developed using **Flutter** and **Firebase**, designed to revolutionize agricultural trade and land management in Sri Lanka. This platform connects farmers, buyers, and sellers while integrating IoT technology for real-time field monitoring, creating a transparent and efficient marketplace for agricultural products.

---

## 📱 Key Features

### 👨‍🌾 Farmer Module
- Directly list and sell agricultural products (rice, seeds, etc.)
- Purchase farming essentials (fertilizers, equipment)
- **IoT integration** for real-time paddy field monitoring
- Process buyer orders and manage transactions

### 🛒 Buyer Module
- Browse and purchase farm products directly from growers
- Transparent pricing without middlemen
- Leave feedback and reviews for farmers

### 🏪 Seller Module
- List agricultural equipment and supplies
- Manage inventory and pricing
- Process farmer orders efficiently

### 👨‍💼 Admin Panel
- Manage all user accounts (farmers, buyers, sellers)
- Monitor platform activities and ensure security
- Approve/remove product listings
- Resolve disputes and provide support
